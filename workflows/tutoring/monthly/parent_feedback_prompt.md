# 월간 학부모 피드백 초안 작성 규칙 (Claude용)

입력: `python monthly/aggregate.py <채점기록 CSV들> --month YYYY-MM` 결과(JSON) (학생별 요약).

## 원칙
- **초안만** 쓴다. 학부모에게 직접 보내지 않는다. 예진 선생님이 읽고 고쳐서 보낸다.
- 숫자는 집계 결과에 있는 것만 쓴다. 없는 숫자를 만들지 않는다. 판독불가 문항은 정답률 계산에서 빠졌다고 적는다.
- 제출일이 8일 미만이거나 채점 문항이 20개 미만이면 "이번 달은 자료가 적어 경향을 단정하기 어렵다"고 쓴다.
- 학생을 다른 학생과 비교하지 않는다.
- 단정적인 평가("머리가 좋다", "집중력이 없다") 대신 관찰된 사실(어떤 단원에서 어떤 실수가 몇 번)을 쓴다.

## 형식 (학생 1명당, 카카오톡 메시지로 붙여넣기 좋게 600자 안팎)

```
안녕하세요, 어머님/아버님. ○○ 수학 담당 김예진입니다.
10월 한 달 숙제 결과를 정리해 드립니다.

[이번 달 숙제]
- 제출 ○일, 채점 ○문항, 정답률 ○%
- 주차별: 1주 ○% → 4주 ○%

[잘하고 있는 점]
- (정답률이 높거나 오른 단원, 꾸준한 제출 등 사실 1~2개)

[보완할 점]
- (가장 많이 틀린 단원과 실수 유형 1~2개, 대표 예시 1개)

[다음 달 계획]
- (보완할 점에 맞춘 수업·복습 퀴즈 계획 1~2개)

궁금하신 점 있으시면 편하게 말씀 주세요. 감사합니다.
```

## 저장
- 학생별 초안을 하나의 문서로 묶어 Google Drive `학부모 피드백/YYYY-MM` 에 저장한다.
- 학생 이름이 들어가므로 공개 GitHub 저장소에는 절대 커밋하지 않는다.
